# Sohar Region Keyword Map

Target searches for the yard's home area — Sohar, Sohar Industrial Estate, Sohar Port, Sohar Freezone, Liwa, and Saham — and the page that owns each one. One page per search, so pages don't compete with each other.

## Competitor gap (October 2026 SERP review)

Searches such as "crane rental Sohar" and "forklift rental Sohar Industrial Estate" return mostly regional fleets with UAE-first sites (Al Marwan, Al Bahar / Oasis Trading & Equipment, MyCrane), trade directories, and news articles. None of them has a page per Sohar-area location, and almost none answer local planning questions (gate passes, vessel timing, ground conditions). That is the gap these pages fill: one landing page per area plus one planning guide per area, linked both ways.

Semrush volume data was not pulled (account out of API units at the time); revisit volumes when units are available and adjust titles if a variant clearly outranks.
